## Life Simulation
This is a simulation of life, 100% realism.

# Requirements
Python v3+, list of required packages & purposes:
| Package Name | Purpose                               |
| ------------ | ------------------------------------- |
| glfw         | Window creation and input handling    |
| PyOpenGL     | OpenGL rendering and graphics         |
| numpy        | Vector math, arrays, and calculations |
| matplotlib   | Simulation statistics and graphs      |
| Pillow       | Image loading and texture processing  |
--------------------------------------------------------
